# Unlock region mapping sources

Generated by `frontend/scripts/unlock-region-data.py`; do not edit mappings by hand.
Input URLs, SHA-256 digests and per-POP evidence are recorded in
`frontend/scripts/unlock-region-data.sources.json`.

- Fastly POP locations: https://www.fastly.com/documentation/guides/getting-started/concepts/using-fastlys-global-pop-network/ — location facts, not page prose.
- Natural Earth v5.1.2 country boundaries: https://www.naturalearthdata.com/about/terms-of-use/ — public domain.
- OurAirports airport locations and countries: https://ourairports.com/data/ — public domain. Used only for coastal points absent from the country polygons, requiring all airports within 5 km to agree on one country.
- i18n-iso-countries v7.14.0: https://github.com/michaelwittig/node-i18n-iso-countries — alpha-3 to alpha-2 codes, including the dataset's Kosovo extension. MIT license follows.
